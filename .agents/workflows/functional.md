// turbo-all
1. **Context Acquisition**: Read `task.md` and `documentation/product_description.md`.
2. **Backlog Refinement**:
   - **Problem Statement**: Define *why* this feature is needed.
   - **Expected Results**: Define measurable outcomes.
   - **Acceptance Criteria**: Scenario list that MUST pass.
   - **Indicators**: Complexity (1-10), Risk (1-10), User Value (1-10).
3. **Backlog Update**: Update `documentation/enriched_product_backlog.md`.
4. **Sign-off**: Pass refined specs to the **Architect** (`/architect`).
