# Product Description - Mermaid

Mermaid is a JavaScript-based diagramming and charting tool that uses Markdown-inspired text definitions and a renderer to create and modify complex diagrams.

## Core Purpose
The main purpose of Mermaid is to help documentation catch up with development ("Doc-Rot" prevention).

## Key Features
- **Flowcharts**: Directed graphs and nodes.
- **Sequence Diagrams**: Actor interactions and loops.
- **Gantt Charts**: Project timelines.
- **Class Diagrams**: OOP structure visualization.
- **State Diagrams**: Finite state machines.
- **Pie Charts**: Proportional data visualization.
- **Entity Relationship Diagrams**: Database schema modeling.
- **User Journey Diagrams**: User experience mapping.
