# Specifications: Mermaid Editor V2

This document details the functional and aesthetic requirements for the new Mermaid Editor V2.

## Visual Mockup
![Editor V2 Mockup](file:///C:/Users/a147982/.gemini/antigravity/brain/7b485c4f-5b7d-45c2-9095-bbffd5538b05/editor_v2_mockup_1774519772745.png)

## Design Identity
- **Aesthetic**: Modern Dark Mode with Glassmorphism.
- **Typography**: `Outfit` for UI, `JetBrains Mono` for Code.
- **Palette**: HSL-based harmonious blues and grays with vibrant accents for primary actions.

## Key Innovation: The Visual Assistant
Editor V2 introduces a central **Assistant Layer** that simplifies diagram creation:

1. **Toolbar Nodes**: Drag-and-drop or click-to-insert nodes specific to the diagram type.
2. **Contextual Intelligence**: A "Next Action" bubble that appears near the cursor suggesting logical completions.
3. **Interactive Overlays**: Small controls (gear icons, color pickers) that appear when hovering over rendered nodes in the preview.

## Feature Breakdown
- **Premium Code Editor**: Integrated line numbers, error highlighting, and snippet support.
- **Smart Rendering**: Debounced, high-performance rendering using the Mermaid core engine.
- **Pro Exports**: Customizable PNG/SVG export with scale, padding, and theme selection.
